COC TWI HYMNAL — STARTER PROJECT

Files:
- index.html: the app interface and starter hymn data
- manifest.json: installable web-app details
- sw.js: basic offline cache for supported hosting

WHAT WORKS IN THIS STARTER
- Search by number, title, and text in the lyric field
- Favorites saved on the same browser/device
- Read hymn details
- Larger/smaller lyric text
- Share hymn text where browser/device supports it
- Basic offline support when served from HTTPS and opened once

IMPORTANT
The three hymn entries are placeholders/sample entries, not the complete hymn lyrics.
Replace the `hymns` array in index.html with hymn text that you have permission to reproduce.
This starter is a web app, not yet a Play Store APK.

EASIEST NEXT STEP
Open index.html in a code editor or browser to preview. For install/offline behavior, it must be hosted on HTTPS; a local file preview alone does not enable the service worker. We can guide you through hosting it from your tablet.
